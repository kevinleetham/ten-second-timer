# Ten Second Timer

A simple iPhone-friendly timer: 10 seconds of hold, 2 seconds of rest, repeating until stopped. Includes distinct sound cues, a large countdown, screen wake lock, and offline caching.

Open the published site in Safari and choose Share → Add to Home Screen. Keep the app open while exercising. Stop resets the timer to 10; switching away stops the timer too.

## Hosting

Publish the root of the main branch with GitHub Pages. No build step or dependencies are needed.
